# Histórico de versões

## v1.0.0-beta.1 — primeira versão oficial de testes

- Popup ancorado de 800 × 600 px aberto pelo ícone da extensão.
- WhatsApp Web renderizado em escala de 86% para melhorar o aproveitamento do espaço.
- Sessão compartilhada com o navegador.
- Monitor invisível para acompanhar mensagens não lidas com o popup fechado.
- Contador de mensagens não lidas no ícone da extensão.
- Alerta sonoro com opção de silenciar.
- Atalho `Ctrl+Shift+Y` para abrir o painel.
- Compatibilidade inicial com Microsoft Edge e Google Chrome 145 ou superior.

### Limitações conhecidas

- O navegador recria o popup sempre que ele é aberto.
- Mudanças futuras no WhatsApp Web podem exigir uma atualização do ZapDock.
